Financial Quotes Monitor (FQM)
Десктопное приложение на C++ для автоматического отслеживания цен на финансовые активы (акции, облигации, токены) на международных и локальных биржах. Система в реальном времени анализирует котировки в фоновом режиме и отправляет пользователю уведомления при падении цены ниже заданного порога.
Стек технологий
Язык: C++ 
Сборка: CMake
Сеть: cpr (C++ Requests) для HTTP/REST API
Работа с данными: nlohmann/json для парсинга, SQLite для локальной БД
Интерфейс: Qt / Dear ImGui
Команда проекта и распределение задач
Проект разрабатывается командой из трех студентов 2 курса ФИТУ группы 521701. Архитектура приложения базируется на многопоточности и паттерне «Производитель-Потребитель» (Producer-Consumer). Задачи строго разделены на три независимых модуля.
1. Сетевое взаимодействие и многопоточность (Куприянова К. В.)
Зона ответственности: Связь приложения с внешними API бирж в изолированном фоновом потоке без блокировки интерфейса.
Настройка и выполнение асинхронных HTTP-запросов к REST API (Binance, БВФБ и др.) с помощью библиотеки cpr.
Десериализация и парсинг входящих потоковых данных в формате JSON (nlohmann/json).
Разработка потокобезопасной очереди (Thread-safe queue) на базе std::mutex и std::condition_variable для передачи данных в ядро.
Обработка сетевых ошибок, таймаутов и лимитов запросов от серверов (Rate limits, HTTP 429).
2. Аналитическое ядро и хранение данных ([Гарбар А. Е.])
Зона ответственности: Локальное хранение пользовательских настроек и математическая обработка поступающих котировок.
Проектирование и интеграция локальной базы данных SQLite для сохранения пользовательского портфеля (список тикеров, целевые цены).
Разработка алгоритма-потребителя (Consumer), который непрерывно читает данные из потокобезопасной очереди и валидирует их.
Реализация логики генерации сигналов (алертов) при фиксации просадки цены актива.
Опционально: Внедрение базовой фильтрации рыночного шума и расчет скользящих средних волатильности.
3. Графический интерфейс и визуализация ([Шипова Д. Р.])
Зона ответственности: Разработка пользовательского интерфейса (GUI) и работа в главном потоке приложения (Main UI Thread).
Верстка главного дашборда: таблицы с текущим состоянием портфеля, окна добавления новых активов и установки пороговых значений (thresholds).
Интеграция графической библиотеки для отрисовки графиков изменения цен в реальном времени.
Организация безопасного чтения данных для UI из структур, обновляемых фоновыми потоками.
Настройка и вызов нативных системных уведомлений в ОС (всплывающие окна в трее) при срабатывании алерта от аналитического ядра. (Tkinter)
